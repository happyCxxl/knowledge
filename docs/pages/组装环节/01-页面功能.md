# 页面功能

组装环节在执行链页上表现为**一张组装卡片**，点卡片上的「详情」打开**环节详情抽屉**（各环节共用同一组件）。卡片与抽屉都是只看不改的展示面，唯一的写操作是卡片上的「触发下一环节」。

## 一、组装卡片

卡片固定 320 × 214，任何状态下尺寸与行位不变。组装卡片是**五个行位**：主体区由体检清单顶替解析卡片的「指标行 + 构成图」。

| 行       | 内容                       | 说明                                                                                         |
|----------|----------------------------|----------------------------------------------------------------------------------------------|
| ① 标题行 | 环节名 + 状态点            | 状态点按任务状态取色                                                                         |
| ② 标识行 | 产物 schema 版本           | 取 `stats.schemaVersion`；取不到时留空并弱化，不显示 `—`                                     |
| ③ 主体区 | 结构体检清单（五行）       | 每行 = 状态点 + 项目名 + 关键量 + 说明；**不显示指标行**（层数 / 标题数 / 元素数都在清单里） |
| ④ 结论行 | 结论一句话                 | 最多两行，超出省略；完整文案在悬停提示里                                                     |
| ⑤ 操作行 | 时间 + 详情 + 触发下一环节 | 未完成显示开始时间，完成显示结束时间；悬停给完整起止（带秒）                                 |

### 体检清单五项

| 项目     | 关键量                | 说明                          | 绿（正常）           | 黄（需关注）        |
|----------|-----------------------|-------------------------------|----------------------|---------------------|
| 章节树   | `N 层`                | `M 标题`                      | 层数 ≥ 2 且有标题    | 层数 < 2 或没有标题 |
| 溯源覆盖 | `N%`                  | `已溯源 / 元素总数`           | ≥ 80%                | < 80%               |
| 疑似续表 | `N 处`                | 起始–结束页（同页给一页）     | 0 处                 | > 0 处              |
| 重复噪声 | `N 段 · M 页`         | 空                            | 重复段与噪声页都为 0 | 任一 > 0            |
| 阅读顺序 | `已重排` / `无坐标 N` | 有值且 > 0 时给「按原序追加」 | 无坐标元素数为 0     | 无坐标元素数 > 0    |

统计缺失（产物读不出来）时整行落到**灰 + `—`**，不冒充真实值。五项的量分别取 `stats` 的 `chapterCount` / `titleCount`、`provenanceCoverage` / `tracedCount`、`continuationCount` / `continuationFromPage` / `continuationToPage`、`repeatedSegmentCount` / `noisePageCount`、`withoutBboxCount`。

### 四态

状态与解析环节同一套：`QUEUED` 排队中 / `RUNNING` 运行中 / `SUCCESS` 成功 / `PARTIAL_SUCCESS` 部分成功 / `FAILED` 失败 / `CANCELLED` 已取消（视觉归为进行中 / 成功 / 部分成功 / 失败四类）。

- 卡片**不显示错误原因**，失败只靠左侧红条与状态点颜色表达，原因在抽屉的失败条里；
- 未完成的节点也出现在链图上（排队中立刻可见）；
- **组装不产出「部分成功」**：无可组装元素时直接失败（`STRUCTURE_EMPTY`）。

### 结论文案（后端给，卡片与抽屉统计条同一句）

| 情形                      | 结论                                                                                              |
|---------------------------|---------------------------------------------------------------------------------------------------|
| 进行中                    | 「正在组装…」（前端文案）                                                                         |
| 失败 / 已取消             | `errorMsg`                                                                                        |
| 成功 / 部分成功，统计缺失 | **留空**（产物不可读时不陈述结论）                                                                |
| 成功 / 部分成功，空树     | 「无任何可组装元素（空树）」                                                                      |
| 成功 / 部分成功，无异常项 | 「结构可用」                                                                                      |
| 成功 / 部分成功，有异常项 | 「结构可用 · 溯源偏低 N% · 疑似续表 N 处 · 重复与噪声待处置」（逐项拼接，正常项不陈述，顺序固定） |

### 触发与分叉

- 组装卡片的「触发下一环节」= **预处理**；分叉点是**被点那张卡的组装产物**（本节点 `productId` 作为 `upstreamProductId` 传给预处理触发接口），同一份文件的多次组装可以各走各的下游；
- 按钮常驻，只有「能点 / 不能点」两态：本节点有产物即可点，不可点时置灰并给原因（任务未完成 → 「任务完成后可用」；已完成但无产物 → 「本次运行没有产物」）；
- 组装有上游：从解析卡片触发而来，上游解析产物由任务记录的 `upstreamProductId` 决定，缺省取该文件最新的解析产物；
- 组装成功后**再次触发是重跑**（新建一条运行，旧任务与旧产物保留），不像解析那样成功后拒绝触发。

## 二、组装详情抽屉

四个固定分区，与解析环节同一套版式（高度锁在视口内，滚动只发生在双栏各自的容器里）：

| 分区   | 固定方式         | 内容                                                                                                                            |
|--------|------------------|---------------------------------------------------------------------------------------------------------------------------------|
| 头部   | 固定             | 文件名 + 状态徽标 + 开始时间 / 耗时 / 任务 ID                                                                                   |
| 统计条 | 固定             | 结论一句话 + 十项统计：元素 / 标题 / 层级分布（一 / 二 / 三级及以下）/ 表格 / 图片 / 疑似续表 / 冲突 / 告警 / 溯源覆盖率 / 耗时 |
| 失败条 | 固定，仅失败出现 | 错误码 + 失败说明 + 建议动作（见下）                                                                                            |
| 双栏   | 唯一伸缩的分区   | 左栏组装后的文档、右栏结构树与产品内容，**各自滚动**                                                                            |
| 底部   | 固定             | 下载原文件 / 复制全部文本（复制的是右栏当前页文本）                                                                             |

### 右栏页签

「结构树 / 元素 / 告警 / 过程」四个，页签条固定在右栏顶部，内容各自滚动；角标是条数（为 0 不显示数字）。

- **打开抽屉默认落在该环节页签表的第一项**（组装 = 「结构树」，解析 = 「元素」）；切换环节或重新打开回到默认页签；
- **同一环节内切换到另一次运行保留当前页签**（用户在同一环节里换运行，页签不跳走）；
- 切页签不影响左栏位置、页码与选中状态。

| 页签   | 内容                                                                                                                                                                   |
|--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 结构树 | 与「元素」页签同一份分页内容，按标题层级缩进：行头 = 类型徽标 + 序号 + 页码 + 行列数 + 展开 / 收起；文本默认两行折叠，点「展开」看全文；正文跟随最近的一个标题缩进一档 |
| 元素   | 关键字过滤（只过滤当前页）+ 元素列表 + 翻页；每条显示类型徽标、序号、页码、来源、表格行列，文本默认两行折叠可展开；「只列预览当前页」开关只对解析环节的原文预览生效    |
| 告警   | 质量告警文案列表 + 冲突列表（主路 / 被裁决方元素 ID + 说明）；两者都空时给空态                                                                                         |
| 过程   | 子步骤列表：步骤名 / 状态 / 耗时 / 告警数 / 错误；失败的步骤带红条，无记录给空态                                                                                       |

分页每页 100 条，底部给「上一页 / 下一页 + 第 X / Y 页 + 共 N 条」；结构树与元素共用同一个页码。

### 左栏：组装后的文档

左栏把**解析 + 组装之后得到的实际内容**正式排成一份文档，数据源是组装详情的 `outline`（统一文档元素、按阅读顺序全量）：

| 元素类型                               | 渲染                                                                                                                                 |
|----------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| `TITLE`                                | 按 `level` 分级：1~4 级各给字号与左缩进，层级再深按 4 级；无文本给「（无标题文本）」                                                 |
| `SECTION`                              | 分节标题（带下边线）；无文本给「（无分节名）」                                                                                       |
| `PARAGRAPH`                            | 成段（保留换行、两端对齐）                                                                                                           |
| `TABLE`                                | 真表格：按 `cells` 的行列落位，表头单元格加底色；产物无单元格明细（或超过 1200 格）时按 `rows×cols` 占位并注明「产物未含单元格明细」 |
| `IMAGE`                                | 虚线占位框，显示图注或「图片（产物未含图片内容）」                                                                                   |
| `LIST` / `FIGURE_CAPTION` / 未枚举类型 | 按文本段渲染                                                                                                                         |
| `HEADER` / `FOOTER`                    | **必须出现**，但弱化（灰字 + 虚线段）并带「页眉 / 页脚」类型标签，避免与正文混淆                                                     |

- 栏头：「组装后的文档 · 共 N 个元素 · M 个标题」，未渲染完时补「已渲染 X」；
- **按需渲染**：一次渲染 80 块，滚动接近底部再追加，不做硬性分页；点定位时先把目标块补进渲染窗口；
- 产物不可读或无产物时给中性提示。

### 双向定位（左栏文档 ↔ 右栏列表）

两侧都以**产物元素 id** 对齐：左栏块键取 `outline.elementId`，右栏行键取 `stage-content` 的 `alignKey`，两者是同一个 id。

| 操作                    | 结果                                                                               |
|-------------------------|------------------------------------------------------------------------------------|
| 点右栏结构树 / 元素某行 | 左栏滚到对应块并高亮；目标块还没渲染时先把它补进渲染窗口                           |
| 点左栏文档里的块        | 右栏对应行选中并滚入视野；目标不在当前页且两侧条数一致时，先切到它所在的那一页再滚 |
| id 不在当前产物里       | 只保留选中，不做顺序近似匹配                                                       |

### 结构树与元素页签的关系

两者读**同一份分页数据**（同一个 `getStageContent` 请求、同一个页码、同一个 `taskId`），区别只在渲染：结构树按 `extra.level` 缩进并可展开全文，元素页签是平的卡片列表。展开状态按行（产物元素 id）记，两个页签共用同一个集合；翻页与换运行时重置。

## 三、失败态与建议动作

| 错误码                          | 建议动作                                                                   |
|---------------------------------|----------------------------------------------------------------------------|
| `STRUCTURE_EMPTY`               | 解析产物里没有可组装的元素（空树）：确认上游解析结果有内容后再触发组装     |
| `STRUCTURE_UPSTREAM_UNREADABLE` | 读不到上游解析产物：确认上游解析已成功产出产物，或重新触发一次解析后再组装 |
| 其它 / 无产物                   | 本次运行没有产物：确认文件可用后，从页面工具栏发起解析（会新建一条执行链） |
