# 自测清单

改完本环节（页面、接口、后端逻辑任一）后手工过一遍。前置条件：中间件已起、后端与前端 dev server 已启动，并准备一个普通用户账号与一个管理员账号、两份知识库（分别属于两人）、一份**带标题与表格且含页眉页脚的 PDF**（能同时命中标题分级与跨页接续）、一份 DOCX、一份 XLSX。

## 卡片四态与体检清单

- [ ] 解析成功后触发组装 → 新节点**立即**出现且状态为「排队中」
- [ ] 运行中：状态点为运行色，状态文字是「组装中」，时间显示**开始时间**
- [ ] 成功：标识行显示产物 `schemaVersion`（取不到时留空并弱化，**不显示** `—`）
- [ ] 成功：结论行给「结构可用」或「结构可用 · 溯源偏低 N% · 疑似续表 N 处 · 重复与噪声待处置」，正常项不出现
- [ ] 失败（空树）：卡片左侧红条，卡片上**不显示**错误原因
- [ ] 体检清单五行都在：章节树 / 溯源覆盖 / 疑似续表 / 重复噪声 / 阅读顺序
- [ ] 章节树：层数 ≥ 2 且有标题 → 绿；标题为 0 → 黄
- [ ] 溯源覆盖：≥ 80% → 绿；< 80% → 黄（含量与 `已溯源 / 元素总数` 说明）
- [ ] 疑似续表：疑似 0 处 → 绿；疑似 > 0 处 → 黄并给起止页（值取 `suspectedContinuationCount`，说明给总数）
- [ ] 重复噪声：显示 `N 段 · M 页`，两者都为 0 → 绿，任一 > 0 → 黄
- [ ] 阅读顺序：无坐标元素为 0 → 绿且给「已重排」；> 0 → 黄并给「按原序追加」
- [ ] 统计缺失（产物读不出来）时五行都是灰 + `—`，不冒充真实值
- [ ] 卡片尺寸 320 × 214 恒定，操作行不被裁剪

## 触发与分叉

- [ ] 任务运行中再次触发 → `40431`
- [ ] 成功后再次触发（从解析卡片发起或工具栏重跑）→ **新建一条组装运行**，旧任务与旧产物仍在
- [ ] 该文件还没有解析产物时触发组装 → `40432`，提示「解析产物不存在，请先触发解析」
- [ ] 从**第二张**解析卡片触发组装 → 组装基于被点那张卡的解析产物（分叉）
- [ ] 本节点无产物时「触发下一环节」置灰但仍在，悬停给原因
- [ ] 点「触发下一环节」并确认 → 新建预处理任务，分叉点是被点那张卡的**组装产物**

## 详情：四个固定分区与滚动

- [ ] 抽屉高度锁在视口内，**外层不出现整页滚动条**
- [ ] 只有左栏文档区与右栏页签内容各自出现滚动条
- [ ] 头部、统计条、页签条、底部分别固定，不随内容滚动
- [ ] 统计条十项都有值（无产物时各项 `—`），放不下时换行

## 页签与默认页签

- [ ] 打开组装详情**默认落在「结构树」**；打开解析详情仍默认落在「元素」
- [ ] 页签顺序是 结构树 / 元素 / 告警 / 过程，角标条数与内容一致（为 0 不显示数字）
- [ ] 在组装里切到「告警」，再切到**同一环节**的另一次运行 → 页签仍是「告警」
- [ ] 关掉抽屉再打开同一张卡 → 回到默认页签（结构树）
- [ ] 从组装详情切到解析详情 → 落在该环节默认页签（元素）
- [ ] 切页签不改变左栏位置与选中状态

## 左栏组装后的文档

- [ ] 栏头给「组装后的文档 · 共 N 个元素 · M 个标题」，未渲染完时带「已渲染 X」
- [ ] 标题按层级分级：1~4 级字号与缩进递增，层级再深按 4 级
- [ ] 段落成段显示，保留原换行
- [ ] 表格渲染成**真表格**：单元格按行列落位、表头有底色；产物无明细或超大时给 `R 行 × C 列` 占位并注明「产物未含单元格明细」
- [ ] 页眉 / 页脚都出现，样式弱化并带「页眉 / 页脚」标签，不与正文混淆
- [ ] 图片给虚线占位框并显示图注
- [ ] 大文档滚动到底部自动追加渲染（不是一次性全渲染），滚动过程不卡顿
- [ ] 无产物 / 产物不可读时左栏给中性提示

## 结构树与元素页签

- [ ] 结构树的行头有类型徽标、序号、页码、行列数与「展开 / 收起」按钮
- [ ] 标题按 `level` 缩进，正文跟随最近的一个标题再进一档；展开后缩进不变、正文不越界
- [ ] 长段落默认两行折叠（超出省略），点「展开」看到**完整文本**，再点收起
- [ ] 表格 / 图片等无正文字段不显示展开按钮，只给占位文案
- [ ] 结构树与元素页签内容条数一致，底部翻页同步（每页 100 条）
- [ ] 翻页或换运行后，展开状态已重置

## 双向定位

- [ ] 点右栏结构树 / 元素某行 → 左栏滚到对应块并高亮
- [ ] 点左栏文档里的块 → 右栏对应行选中并滚入视野
- [ ] 左栏点第 100 条以后的块 → 右栏自动切到对应页再滚过去
- [ ] 右栏点还没渲染的块 → 左栏先追加渲染再滚到位
- [ ] 对不上的元素（不在当前产物里）只保留选中，不跳到别的块

## 失败态

- [ ] 空树（`STRUCTURE_EMPTY`）：失败条给错误码 + 说明 + 「确认上游解析结果有内容后再触发组装」
- [ ] 上游不可读（`STRUCTURE_UPSTREAM_UNREADABLE`）：失败条给「确认上游解析已成功产出产物，或重新触发一次解析后再组装」
- [ ] 其它失败或无产物：失败条给通用建议（从页面工具栏发起解析 / 确认文件可用）
- [ ] 失败的运行**没有产物**：统计条各项 `—`、左栏给中性提示、过程页签能看卡在哪一步

## 越权与鉴权

- [ ] 用 A 账号登录，直接请求 B 账号文件结果的 `structure-detail` / `stage-content?stage=STRUCTURE` → **40401**，界面表现为打不开而不是 500
- [ ] 用管理员账号打开 B 账号的文件结果 → **正常可访问**
- [ ] 未登录直接调这两个接口 → **40101**
- [ ] 用一个不存在的 `fileResultId` → 仍按原语义返回（记录不存在不等于越权）
