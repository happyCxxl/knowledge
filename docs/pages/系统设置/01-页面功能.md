# 页面功能

页面用全局骨架（`.page` / `.page-head` / `.page-title`，见 `../../../web/src/styles/page-shell.css`），页头之下是**一张小卡**（`.setting-card`，宽 560px、高 268px，取值照个人中心的 `.profile-card`）。卡片**尺寸固定**：高度不随存储源数量变化，卡内字段多时在信息块里滚，卡片本身在视口放不下时由卡片区（`.setting-body`）滚。卡内从上到下两段——**存储源下拉**（含「启用」按钮）与「**当前启用**」信息块；确认弹窗是浮层，不占卡内位置。整页只有一类写动作：把某个存储源设为当前启用。静态样式示例见同目录 `示例-系统设置-数据源卡片.html`。

```
┌ 文件服务写入后端   新上传与新任务写到当前启用的存储源 ────────────┐
│ 存储源  [ MinIO · minio          ▾ ]                  [启用]      │
│ 当前启用  MinIO              已接入 · 最近探测 2026-02-11 10:24  │
│  类型    MinIO  minio                                            │
│  密钥    已配置                                                  │
│  endpoint        http://localhost:9000                           │
│  fileBucket      files                                           │
│  artifactBucket  artifacts                                       │
└──────────────────────────────────────────────────────────────────┘
```

## 存储源下拉与「启用」

- 下拉是 `el-select`，只列 `status === 'ENABLED'` 的存储源（停用的不进候选），选项文案是 `名称 · 类型码`（`SystemSettingView.sourceLabel`）；一个候选都没有时下拉禁用，占位文案「暂无启用的存储源」。
- 进页面时默认选中**当前启用**的那一项（清单里 `current === true` 的那一行）；清单里没有当前启用项时选中项为空。每次重新取清单时，选中项还在候选里就保持不变，已不在候选里就回落到当前启用项。
- 「启用」按钮文案固定读「启用」，在三种情况下禁用：没有候选或选中项为空、选中项就是当前启用项、有请求在跑（清单读取中或切换进行中）。其余情况可点，点了走下面「设为当前：两步走」。
- 换选下拉里的另一项只是**准备切过去**：信息块讲的是当前启用项，不随选中项变化，直到确认启用并重新取过清单。

## 「当前启用」信息块

信息块只讲**当前启用的那个存储源**，分块头与字段行两层：

| 位置   | 内容                                                                                                                                                                   |
|--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 块头   | 「当前启用」+ 存储源名称（`name`）+ 状态四态文案，`probeAt` 非空时补「· 最近探测 <日期> <时间>」                                                                       |
| 类型   | 类型展示名与类型码同列（`storageTypeName` 与 `storageType`，如 `MinIO minio`）                                                                                         |
| 密钥   | `credentialConfigured` 为真时显示一行「密钥 已配置」，为假时这一行不显示                                                                                               |
| 参数行 | `params` 里的键与值逐行显示，键名就是参数名（`minio`：`endpoint` / `fileBucket` / `artifactBucket`；`local`：`rootDir` / `fileDir` / `artifactDir`），值按等宽字体渲染 |

`local` 这类没有密钥类参数的类型，`credentialConfigured` 同样读作真，密钥行照常显示「已配置」；访问密钥与私有密钥不进 `params`，界面上没有它们的取值。

- 信息块高度固定，字段行超出时**块内滚动**，卡片高度不变。
- 下拉里选了别的存储源时，这一块**仍显示当前启用的那个**；确认启用并重新取过清单之后才换成新源。
- 清单里没有当前启用项（全部行停用，或当前启用是回落注册的那条内置定义）时，块内读「暂无启用的存储源」，读取期间读「加载中…」。

## 状态四态

判定顺序是先看 `registered`、再看 `probeOk`：

| 态       | 条件                                     | 呈现                |
|----------|------------------------------------------|---------------------|
| 已接入   | `registered = true` 且 `probeOk = true`  | 绿点 + 「已接入」   |
| 连接失败 | `registered = true` 且 `probeOk = false` | 黄点 + 「连接失败」 |
| 未测试   | `registered = true` 且 `probeOk = null`  | 灰点 + 「未测试」   |
| 未接入   | `registered = false`                     | 灰点 + 「未接入」   |

状态在页面上只出现一次，落在信息块块头上，讲的是当前启用的那个存储源；`probeAt` 非空时文案后面接「· 最近探测 <日期> <时间>」，「连接失败」这一态另有悬停提示给出同一个时间。`probeOk` 与 `probeAt` 读的是行上缓存的上一次探测结论与时间，由启动初始化与设为当前两处回写；页面自身不发起探测。

## 设为当前：两步走

1. **取影响面**：点「启用」调设置当前预览接口，这一步**不落库、不切换、不探活**，只做目标可用性校验与影响面统计。
2. **确认弹窗**：标题「启用 <存储源名称>」，正文首行是后端返回的 `message`，下面两块计数并排——「排队中 · 将跑不了」与「执行中 · 将跑不了」。按钮是「取消」与「确认启用」；点「取消」或点遮罩空白即结束，不发下一个接口；请求进行中两个按钮都禁用。
3. **启用**：确认后调设为当前接口，成功后重新取一次清单——下拉选中项与信息块一起跟着新值走，提示「已启用<存储源名称>」。任一步失败（目标已停用、参数缺项、探测不过、非管理员）时由拦截器弹出提示，页面状态保持不变。

## 页面不做的几件事

- **不新增、不编辑、不停用、不删除存储源**：数据源只能由 `application.yml` 的 seed 或库内 SQL 维护，`status = DISABLED` 的行在页面上没有任何操作入口。
- **没有连接测试**：页面不发起探测调用，状态读的是库里缓存的结论两列。
- **没有刷新按钮**：清单在进页面时取一次，启用成功后重新取一次，没有轮询。
- **不显示密钥**：`params` 只给非密钥参数，密钥类参数只由「密钥 已配置」一行体现，界面上没有回显入口。
- **不改 `application.yml`**：页面的写动作只落 `kb_storage_source` 的 `is_current`（先清后置）与这次探测的结论两列，另留一条审计，配置文件始终不动。
