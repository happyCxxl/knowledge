# 页面功能

切片环节在执行链页上表现为**一张切片体检卡片**，点卡片上的「详情」打开**环节详情抽屉**（各环节共用同一组件）。卡片与抽屉都是只看不改的展示面，唯一的写操作是卡片上的「触发下一环节」。

## 一、切片卡片

卡片固定 320 × 214，任何状态下尺寸与行位不变。切片卡片是**五个行位**：主体区由切片体检清单顶替解析卡片的「指标行 + 构成图」。

| 行       | 内容                       | 说明                                                                                            |
|----------|----------------------------|-------------------------------------------------------------------------------------------------|
| ① 标题行 | 环节名 + 状态点            | 状态点按任务状态取色                                                                            |
| ② 标识行 | 策略版本                   | 取执行树节点的策略版本（name-version 串，如 `chunk-hybrid-v1`）；取不到时留空并弱化，不显示 `—` |
| ③ 主体区 | 切片体检清单（五行）       | 每行 = 状态点 + 项目名 + 关键量 + 说明；**不显示指标行**（片数与类型分布都在清单里）            |
| ④ 结论行 | 结论一句话                 | 最多两行，超出省略；完整文案在悬停提示里                                                        |
| ⑤ 操作行 | 时间 + 详情 + 触发下一环节 | 未完成显示开始时间，完成显示结束时间；悬停给完整起止（带秒）                                    |

### 切片体检清单五行

| 项目     | 关键量                         | 说明列                                                   | 绿（正常）        | 黄（需关注）    |
|----------|--------------------------------|----------------------------------------------------------|-------------------|-----------------|
| 切片条数 | `chunkCount`（含父片）         | `正文 N · 表格 M · 图片 K · 父片 J · 兜底 L`（五类分布） | 有片              | —               |
| 超限片   | `overSoftMaxCount`（> 软上限） | `超 800 字 N 片 · 已按 500 字递归切分`                   | 0 片              | > 0 片          |
| 父片     | `parentCount`                  | `不产向量（向量化时跳过）`                               | 0 片              | > 0 片          |
| 孤儿片   | `orphanCount`                  | `无同节邻居，未并入正文片`                               | 0 片              | > 0 片          |
| 进入切片 | `routedElementCount`           | `跳过 N（预处理剔除与重复份）`                           | 有元素进入（> 0） | —（缺统计记灰） |

口径要点：

- **片数是虚高的**：默认策略下每个章节多出一条 `contentType=SECTION` 的**父片**，它计入 `chunkCount`，但向量化时被跳过（不产向量）——卡片把「父片」单列一行并注明"不产向量"，看片数时不能直接当成检索条数；
- 「切片条数」的说明列给五类分布（正文 / 表格 / 图片 / 父片 / 兜底），缺统计的类型不出现；
- 「超限片」的关键量是**超过软上限**（`softMaxLen`，默认 1000）的片数，说明列同时给超过目标片长（`targetMaxLen`，默认 800）的片数与兜底切分参数；
- 「进入切片」与「跳过」的口径来自**上游预处理视图**（跳过 = 剔除态与重复份，即不进切片的那批元素）；上游产物读不到时这两个数不下发，本行落**灰 + `—`**；
- 统计缺失（产物读不出来）时整行落到**灰 + `—`**，不冒充真实值。

### 四态

状态与解析环节同一套：`QUEUED` 排队中 / `RUNNING` 运行中 / `SUCCESS` 成功 / `PARTIAL_SUCCESS` 部分成功 / `FAILED` 失败 / `CANCELLED` 已取消（视觉归为进行中 / 成功 / 部分成功 / 失败四类）。

- 卡片**不显示错误原因**，失败只靠左侧红条与状态点颜色表达，原因在抽屉的失败条里；
- **切片会产出「部分成功」**：某个切片器对某个元素抛异常时，其余片照常产出，异常计入子步骤告警与结论。

### 结论文案（后端给，卡片与抽屉统计条同一句）

| 情形                      | 结论                                                                                                      |
|---------------------------|-----------------------------------------------------------------------------------------------------------|
| 进行中                    | 「正在切片…」（前端文案）                                                                                 |
| 失败 / 已取消             | `errorMsg`                                                                                                |
| 成功 / 部分成功，统计缺失 | **留空**（产物不可读时不陈述结论）                                                                        |
| 成功 / 部分成功，空集合   | 「没有产出任何切片（无可切内容）」                                                                        |
| 成功 / 部分成功，无异常项 | 「全部为正文 / 表格 / 图片片，未走兜底」                                                                  |
| 成功 / 部分成功，有异常项 | 「片数含 N 条不产向量的父片；K 片走了兜底切分；J 片无同节邻居；M 片超过软上限」（只陈述异常项，顺序固定） |

### 触发与分叉

- 切片卡片的「触发下一环节」= **向量化**；分叉点是**被点那张卡的切片产物**（本节点 `productId` 作为 `upstreamProductId` 传给向量化触发接口），同一份文件的多次切片可以各走各的下游；
- 按钮常驻，只有「能点 / 不能点」两态：本节点有产物即可点，不可点时置灰并给原因（任务未完成 → 「任务完成后可用」；已完成但无产物 → 「本次运行没有产物」）；
- 触发时按**策略四档**解析生效版本（见 `03-接口逻辑.md`），策略快照在触发时固定，执行只用快照；成功后**再次触发是重跑**（新建一条运行，旧任务与旧产物保留）。

## 二、切片详情抽屉

四个固定分区，与解析 / 组装 / 预处理同一套版式（高度锁在视口内，滚动只发生在双栏各自的容器里）：

| 分区   | 固定方式         | 内容                                                                                       |
|--------|------------------|--------------------------------------------------------------------------------------------|
| 头部   | 固定             | 文件名 + 状态徽标 + 开始时间 / 耗时 / 任务 ID                                              |
| 统计条 | 固定             | 结论一句话 + 十格统计：元素 / 切片 / 正文 / 表格 / 图片 / 父片 / 兜底 / 超限 / 跳过 / 耗时 |
| 失败条 | 固定，仅失败出现 | 错误码 + 失败说明 + 建议动作（`CHUNK_EMPTY` / `CHUNK_FAILED` 各给对应建议）                |
| 双栏   | 唯一伸缩的分区   | 左栏切片结果、右栏切片与兜底片等，**各自滚动**                                             |
| 底部   | 固定             | 下载原文件 / 复制全部文本（复制的是右栏当前页文本）                                        |

统计条十格的口径：**元素** = 进入切片的元素数 + 跳过（= 上游视图元素总数）、**切片**含父片、**父片**与**兜底**单列、**超限**取超过软上限的片数、**跳过**取预处理剔除与重复份。

### 右栏页签

「切片（默认）/ 兜底片 / 父片 · 孤儿 / 来源对照 / 过程」五个，页签条固定在右栏顶部，内容各自滚动；角标是条数（为 0 不显示数字）。

- **打开抽屉默认落在该环节页签表的第一项**（切片 = 「切片」）；切换环节或重新打开回到默认页签；
- **同一环节内切换到另一次运行保留当前页签**；切页签不影响左栏位置与选中状态。

| 页签        | 内容                                                                                                                             |
|-------------|----------------------------------------------------------------------------------------------------------------------------------|
| 切片        | 分页片列表：类型徽标（正文 / 表格 / 图片 / 父片 / 兜底）+ 片号 + 标题路径 + 内容；关键字过滤只作用于当前页                       |
| 兜底片      | **只列走兜底切分的片**（`contentType=FALLBACK`）：片号 + 类型 + 标题路径/字数/来源数 + 内容                                      |
| 父片 · 孤儿 | **只列没有父片的片**（父片与孤儿片都在其中，子片不在）：片号 + 类型（父片 / 孤儿片）+ 说明 + 内容                                |
| 来源对照    | 跟随左栏选中的片：片号 / 类型 / 标题路径 / 字符数 / **来源元素个数** / 页码范围 / 表格引用 / 兜底原因，并注明来源元素只给个数    |
| 过程        | 六步子步骤：内容路由 / 正文切片 / 表格切片 / 图片切片 / 兜底切片 / 父子关系补充（步骤名 / 状态 / 耗时 / 命中数 / 告警数 / 错误） |

「兜底片」与「父片 · 孤儿」是**按需加载**的：切到该页签时才取列表（角标数直接用详情统计，不必先请求）；两个页签各自记页码，每页 100 条。

### 左栏：切片结果

左栏把该次运行的片排成一份可读结果，每片一块：**片号 + 类型标签 + 标题路径 / 字数 / 来源元素个数 + 内容**。顶部有**三档切换**：

| 档位   | 显示                               |
|--------|------------------------------------|
| 全部   | 按阅读序渲染全部片（默认档）       |
| 兜底片 | 只渲染 `contentType=FALLBACK` 的片 |
| 父片   | 只渲染被挂子片的父片               |

排版的几条口径：

- **按阅读序重排**：切片产物里的顺序是"父片全部在前、子片随后、孤儿片最后"（归档序），左栏先按"子片首次出现"把**父片锚点与其全部子片成组**输出，再把没有子片的父片与**孤儿片按归档序补到末尾**——这样父片落在它所属章节的位置，孤儿片集中在末尾；
- **表格片渲染成真表格**：表格片的 content 是 Markdown 管道表（表头行 + 分隔行 + 数据行），左栏解析成网格并按表格排版（表头单元格带底色），解析不出表格时按普通文本渲染；
- 片块的说明列：标题路径 · 字数 · `来源 N 元素`；父片补 `N 个子片 · 不产向量`，兜底片补兜底原因（缺失时给"超长内容按兜底参数递归切分"），表格片补 `表头随片 · R 行 × C 列`；
- 片块按形态给左边框色：父片（绿）/ 兜底片（黄）/ 表格片（蓝）；
- 栏头：「切片结果 · 共 N 片 · 按阅读序」，切到某个档位时补「当前档 X」，未渲染完时补「已渲染 Y」；
- **按需渲染**：一次渲染 80 块，滚动接近底部再追加，不做硬性分页；点定位时先把目标块补进渲染窗口；
- 产物不可读或无产物时给中性提示。

### 双向定位（左栏切片结果 ↔ 右栏列表）

两侧都以**片 ID（`chunkId`，形如 `chunk-0012`）**对齐：左栏块键取详情里的 `chunkId`，右栏行键取 `stage-content` 的 `alignKey`，两者是同一个值。

| 操作                 | 结果                                                                                    |
|----------------------|-----------------------------------------------------------------------------------------|
| 点右栏任一片行       | 左栏滚到对应块并高亮；目标块还没渲染时先补渲染窗口                                      |
| 点左栏的片块         | 右栏对应行选中并滚入视野                                                                |
| 目标行不在右栏当前页 | 先换到它所在的那一页：**换页按片自身的 `orderNo` 算**（左栏是阅读序，块下标与页序不同） |
| id 不在当前产物里    | 只保留选中，不做顺序近似匹配                                                            |

## 三、失败态与建议动作

| 错误码         | 建议动作                                                                   |
|----------------|----------------------------------------------------------------------------|
| `CHUNK_EMPTY`  | 上游清洗结果缺失或没有可切内容：确认预处理已成功产出产物后再触发切片       |
| `CHUNK_FAILED` | 切片执行异常：看「过程」页签里失败的步骤，必要时重新触发一次切片           |
| 其它 / 无产物  | 本次运行没有产物：确认文件可用后，从页面工具栏发起解析（会新建一条执行链） |
