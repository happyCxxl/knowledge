# 自测清单

改完切片环节的卡片、抽屉或后端读取侧后，按下表手工过一遍。前置：库里有一个已解析 → 已组装 → 已预处理的文件结果，且该库绑定了启用中的切片策略。

## 一、卡片

- [ ] 四种状态各看一眼：排队中 / 运行中（文案「正在切片…」）/ 成功 / 失败；卡片尺寸与行位在四态下都不变
- [ ] 标识行显示策略版本（形如 `chunk-hybrid-v1`）；换一个没有策略快照的历史任务，该行留空而不是显示 `—`
- [ ] 体检清单五行齐全（切片条数 / 超限片 / 父片 / 孤儿片 / 进入切片），每行都有状态点 + 项目名 + 关键量 + 说明
- [ ] 「切片条数」的说明列给出五类分布（正文 / 表格 / 图片 / 父片 / 兜底），且**片数与四类之和 + 父片对得上**
- [ ] 「父片」一行注明「不产向量（向量化时跳过）」，数量与详情统计条的「父片」一致（**片数虚高的来源**）
- [ ] 「孤儿片」为 0 时状态点绿、大于 0 时黄；说明列固定为「无同节邻居，未并入正文片」
- [ ] 「超限片」的关键量是超过软上限（默认 1000）的片数，说明列同时给"超 800 字 N 片"与"已按 500 字递归切分"
- [ ] 「进入切片」= 上游视图元素 − 跳过，说明列在跳过为 0 时不显示括号内容；上游产物读不到时本行落灰 + `—`
- [ ] 结论行与详情统计条的结论**同一句话**；失败时显示失败原因；产物读不出来时结论留空（不得出现编造的结论）
- [ ] 「触发下一环节」= 向量化，分叉点是本卡片的切片产物；完成后再次触发是重跑（新建运行，旧运行仍能在执行树上点开）

## 二、触发与策略

- [ ] 从预处理卡片点「触发下一环节」→ 新建切片任务，分叉点是被点那张卡的预处理产物
- [ ] 库内绑定启用中的切片策略版本 → 触发生效的是该版本（对比卡片标识行）
- [ ] 指定一个不存在或未启用的策略版本 ID → 失败提示 40433
- [ ] 触发时该文件还没有预处理产物 → 40432
- [ ] 触发瞬间连点两次 → 第二次 40431（进行中拒绝）
- [ ] 上游预处理产物被清掉后触发 → 任务落 `CHUNK_EMPTY`，卡片失败，抽屉失败条给出对应建议

## 三、详情抽屉

- [ ] 打开抽屉：头部（文件名 / 状态徽标 / 开始时间 / 耗时 / 任务 ID）齐全
- [ ] 统计条十格齐全：元素 / 切片 / 正文 / 表格 / 图片 / 父片 / 兜底 / 超限 / 跳过 / 耗时
- [ ] 「元素」= 进入切片 + 跳过（与卡片「进入切片」一行的两个数对得上）
- [ ] 关闭再打开、或切到另一个环节再回来 → 默认落在「切片」页签
- [ ] 同一环节内切换到另一次运行 → 保留当前页签；换环节 → 回到该环节默认页签
- [ ] 滚动只发生在左右栏内部：头部、统计条、底部按钮始终可见
- [ ] 失败任务的失败条：错误码 + 说明 + 建议动作（`CHUNK_EMPTY` / `CHUNK_FAILED` 各给对应建议）

## 四、右栏页签

- [ ] 「切片」是默认页签：类型徽标（正文 / 表格 / 图片 / **父片** / 兜底）+ 片号 + 标题路径 + 内容；长文本折叠可展开
- [ ] 「切片」翻页与关键字过滤只作用于当前页；角标数 = 该次运行的片数（含父片）
- [ ] 「兜底片」切到该页签才发请求（打开抽屉时不发）；只列 `contentType=FALLBACK` 的片；角标数与统计条的「兜底」一致
- [ ] 「父片 · 孤儿」同上按需加载；只列**没有父片的片**（父片与孤儿片都在其中，子片不在）；角标数 = 父片 + 孤儿片
- [ ] 两个过滤页签各自翻页：切走再切回来保留页码；页脚给「共 N 条 · 每页 100」
- [ ] 「来源对照」跟随左栏选中的片：给片号 / 类型 / 标题路径 / 字符数 / **来源元素个数** / 页码范围 / 表格引用 / 兜底原因；未选片时给引导文案
- [ ] 「过程」页签六步齐全（内容路由 / 正文切片 / 表格切片 / 图片切片 / 兜底切片 / 父子关系补充），异常步骤带红条与错误摘要

## 五、左栏「切片结果」

- [ ] 栏头显示「切片结果 · 共 N 片 · 按阅读序」；切档时补「当前档 X」
- [ ] **按阅读序**：父片紧跟它的子片成组出现（不是父片全部堆在开头），孤儿片集中在末尾
- [ ] 每片给：片号（`#12`）+ 类型标签 + 说明列（标题路径 · 字数 · `来源 N 元素`）
- [ ] 父片的说明列给「N 个子片 · 不产向量」；兜底片给兜底原因；表格片给「表头随片 · R 行 × C 列」
- [ ] **表格片渲染成真表格**：表头单元格带底色，行列与片内容一致；解析不出表格的表格片按普通文本渲染
- [ ] 三个档位（全部 / 兜底片 / 父片）切换后只影响左栏，右栏页码与选中不变
- [ ] 长文档滚动到底会继续追加渲染（一次 80 块），不出现白屏或一次性卡死
- [ ] 产物不可读的任务：左栏给中性提示，不显示半截结果
- [ ] 换一次运行 → 左栏回到「全部」档、渲染窗口从头开始

## 六、双向定位

- [ ] 点右栏某片行 → 左栏滚到对应块并高亮（目标未渲染时先补渲染窗口）
- [ ] 点左栏的片块 → 右栏对应行选中并滚入视野
- [ ] 目标行不在右栏当前页时 → 换到它所在的那一页（**按片自身 `orderNo` 算**，不是左栏块下标）
- [ ] 在「兜底片」「父片 · 孤儿」页签点行 → 左栏滚到该片（这两个页签的键与左栏同源）
- [ ] id 不在当前产物里 → 只保留选中，不做近似匹配

## 七、未配置环节与边界

- [ ] 向量化（EMBED）等未配置展示口径的环节：左栏给中性提示，**不再尝试加载原文件**、不出现"原文件加载中…"常驻
- [ ] 用别人的 `fileResultId` 打开详情 / 触发 → 40401（与"不存在"同一响应）
- [ ] 未登录（清掉令牌）→ 40101
- [ ] `taskId` 传另一个文件的任务 → 40001

## 八、回归一眼（解析 / 组装 / 预处理）

- [ ] 解析卡片与详情：构成图、统计项、左栏原文预览、四个页签、页码联动与双向定位与本轮之前一致
- [ ] 组装卡片：体检清单五行与结论行不变；详情左栏「组装后的文档」排版（真表格与层级）与「结构树」页签分页不变
- [ ] 预处理卡片：体检清单五行（剔除元素 / 仅标记 / 字段规范 / 文本改写 / 保留元素）不变
- [ ] 预处理详情：左栏「只看保留 / 看被剔除」切换与灰化划线、右栏「剔除内容」按需加载与「字段」页签都不变
- [ ] 三个环节的详情左上标题分别是「原文预览 / 组装后的文档 / 清洗后的正文」，切片是「切片结果」
## 九、策略页（切片）

- [ ] 四条路由的算法下拉里，未上线的算法**置灰可见**，标签写明原因（语义切片 / 语义断点 = 依赖嵌入能力；OCR = 依赖解析环节的 OCR 能力；视觉摘要 / 多模态向量 = 依赖多模态模型）
- [ ] 每条算法的参数输入框，标签上都带允许范围（与后端 `ChunkParam` 同源），例如「目标片长（100~5000）」
- [ ] 结构混合 / 句子聚合都给出「目标片长」与「软上限」两个参数；「表 + 引导段落」给出「引导段截断长度」+「短行阈值」+「行组大小」三个参数
- [ ] 越界值保存时被后端拦下（40001，提示"参数越界: body.targetMaxLen（允许 100~5000）"），页面不再出现"填了才知道范围"的情况
- [ ] 「表格并入正文流」与表格算法「表 + 引导段落」同时开时，页面当场给互斥提示，而不是等保存失败
