# 登录认证（登录 / 注册）

登录卡与注册卡共用同一套翻转舞台与同一份请求层约定，故算一个功能单元。自助改密改在「个人中心」页里，归到 `../个人中心/`。

| 项         | 值                                           |
|------------|----------------------------------------------|
| 路由       | `/login`（`meta.public`，全站唯一免登录页）  |
| 前端视图   | `../../../web/src/views/login/LoginView.vue` |
| 前端接口层 | `../../../web/src/api/auth.ts`               |
| 后端       | `knowledge-auth` 模块（`AuthController`）    |
| 涉及接口   | `POST /auth/login`、`POST /auth/register`    |

**归属规则**（同一处改动该写进哪份，按这个放）：

- 路径、请求体、响应字段、错误码 → `02-接口交互.md`；
- 校验顺序、落库、副作用、边界条件 → `03-接口逻辑.md`；
- 两边都受影响时各写一句并互相引用，**不复述**；
- 通用口径（错误码总表、登录态、限流机制）只在 `../../README.md` 的「全局约定」章写一次。
