# 页面功能

页面用全局骨架（`.page` / `.page-head` / `.page-panel`，见 `../../../web/src/styles/page-shell.css`），面板内是**左右两栏**：左侧一张身份卡（固定 360px），右侧两块表单并排。面板自身不滚动：两栏按**内容自适应高度**并在面板内垂直居中，保存按钮贴卡片底部，空缺落在表单与按钮之间（读作布局间距，而不是卡片里的洞）。

```
┌ 身份卡 360px ──────────┐ ┌ 基本资料 ──┐ ┌ 修改密码 ──┐
│  118px 头像（可更换）   │ │ 真实姓名   │ │ 当前密码   │
│  姓名 + 角色标签 + 状态 │ │ 邮箱       │ │ 新密码     │
│  [更换头像] [移除]      │ │ 手机号     │ │ 确认新密码 │
│  资料完善度 chips       │ │ [保存]     │ │ [保存]     │
│  用户名 / 创建 / 更新时间│ └────────────┘ └────────────┘
│  [退出登录]             │
└────────────────────────┘
```

- **身份卡**：头像（设置过显示图片，否则姓名首字）、姓名、角色标签与状态点、资料完善度、三个只读事实（用户名 / 创建时间 / 更新时间，「退出登录」贴底）。
- **状态点**：启用为翡翠绿并带 3px 同色淡光，停用为红色 —— 一眼看出账号是否可用；角色用标签、状态用圆点，两种信息不混。
- **两块表单各自独立提交**：`保存` 按钮分别只提交自己那块，某块校验不过不影响另一块。
- **头像**：走 `POST /user/avatar` 上传（隐藏的文件选择框触发，只接受 PNG / JPG / WebP，后端按文件头魔数二次校验）；成功后把返回的新地址写进 store，**布局壳的两处头像同时更新**，不必重新登录；「移除」即时回落姓名首字。
- 真实姓名必填且最长 64（与库中 `display_name VARCHAR(64)` 一致）；邮箱做格式校验；手机号按 `^[0-9+()\- ]{6,32}$` 校验（宽松，允许 `+ - ( )` 与空格）；新密码 8-10 位且两次一致。这些校验只在前端，后端仍会再校验一次。
- 邮箱 / 手机号**留空即清空**：提交空串，后端按 `null` 存（见 `03-接口逻辑.md`）。

## 进页面与保存后的行为

- **进页面**调一次 `GET /user/profile`，用服务端最新值填表与刷新只读区 —— 换设备登录或管理员改过之后，本地用户快照可能已经不是最新的。
- **保存基本信息成功后**：调 `authStore.setDisplayName` 同步布局壳的姓名展示（不必重新登录），提示「保存成功」，并重新拉取一次资料刷新「更新时间」。
- **修改密码成功后**：用响应里补签的令牌调 `authStore.replaceToken` **替换**本地令牌（写回令牌当前所在的那一档存储，不改变「记住我」的选择），清空三个输入与校验状态，并提示「密码已修改，其他设备需用新密码重新登录」。**不替换令牌会导致下一次请求就因令牌版本不匹配而失效**——服务端在改密时递增了 `token_version`。

## 与布局壳的关系

本页是壳的子路由，因此：顶栏的**返回按钮**由壳的返回表驱动（本页在表里，目标是「首页」）；内容区高度由壳的骨架决定；页面标题与说明写在 `.page-head`，与其它页面版式一致。
