# 自测清单

改完预处理环节的卡片、抽屉或后端读取侧后，按下表手工过一遍。前置：库里有一个已解析 → 已组装的文件结果，且该库绑定了启用中的预处理策略。

## 一、卡片

- [ ] 四种状态各看一眼：排队中 / 运行中（文案「正在预处理…」）/ 成功 / 失败；卡片尺寸与行位在四态下都不变
- [ ] 标识行显示策略版本（形如 `preproc-default-v1`）；把产物挪走或换一个没有策略快照的历史任务，该行留空而不是显示 `—`
- [ ] 体检清单五行齐全（剔除元素 / 仅标记 / 字段规范 / 文本改写 / 保留元素），每行都有状态点 + 项目名 + 关键量 + 说明
- [ ] 「剔除元素」的关键量 = **不进切片的总数**（重复份 + 剔除态），说明列给 `重复份 N · 剔除 M，不进检索`；只标注、没剔除的任务这一行应为 0 且状态点绿
- [ ] 「仅标记」的关键量按状态拆开显示（页眉 / 页脚 / 目录 / 噪声 / 重复份），零值项不出现；默认策略下这一行通常非 0（属正常）
- [ ] 「字段规范」按类型拆（金额 / 日期 / 面积 / 证书号）；没有字段时记灰 + `—`，不要显示成 0
- [ ] 「保留元素」给保留数与占比（`占 N%`）；有剔除时状态点黄、无剔除时绿
- [ ] 结论行与详情统计条的结论**同一句话**（同一接口字段），失败时显示失败原因
- [ ] 产物读不出来的任务：五行全部灰 + `—`、结论留空（**不得出现编造的结论**）
- [ ] 「触发下一环节」= 切片，分叉点是本卡片的预处理产物；完成后再次触发是重跑（新建运行，旧运行仍能在执行树上点开）
- [ ] 本节点无产物时按钮置灰并给原因（任务未完成 / 没有产物）

## 二、触发与策略

- [ ] 从组装卡片点「触发下一环节」→ 新建预处理任务，分叉点是被点那张卡的组装产物
- [ ] 库内绑定启用中的预处理策略版本 → 触发生效的是该版本（对比卡片标识行）
- [ ] 指定一个不存在或未启用的策略版本 ID → 失败提示 40433
- [ ] 触发时该文件还没有组装产物 → 40432
- [ ] 触发瞬间连点两次 → 第二次 40431（进行中拒绝）
- [ ] 上游组装产物被清掉后触发 → 任务落 `PREPROCESS_EMPTY`，卡片失败，抽屉失败条给出对应建议

## 三、详情抽屉

- [ ] 打开抽屉：头部（文件名 / 状态徽标 / 开始时间 / 耗时 / 任务 ID）齐全，**没有「第 N 次执行」**
- [ ] 统计条八格齐全：元素 / 保留 / 剔除 / 仅标记 / 重复 / 字段 / 告警 / 耗时
- [ ] 关闭再打开、或切到另一个环节再回来 → 默认落在「清洗结果」页签
- [ ] 同一环节内切换到另一次运行 → 保留当前页签；换环节 → 回到该环节默认页签
- [ ] 滚动只发生在左右栏内部：头部、统计条、底部按钮始终可见
- [ ] 只有双栏之间有分隔条可拖动，分隔条拖到两端有上下限（不出现 0 宽或覆盖整屏）
- [ ] 失败任务的失败条：错误码 + 说明 + 建议动作（`PREPROCESS_EMPTY` / `PREPROCESS_FAILED` 各给对应建议）
- [ ] 底部「下载原文件」与「复制全部文本」可用（复制的是右栏当前页文本）

## 四、右栏页签

- [ ] 「清洗结果」是默认页签：类型徽标 + 序号 + 页码 + 来源 + 表格行列齐全，长文本两行折叠、可展开
- [ ] 「清洗结果」翻页与关键字过滤只作用于当前页；角标数 = 该次运行的元素总数
- [ ] 「剔除内容」切到该页签才发请求（打开抽屉时不发）；只列不进切片的元素（重复份与剔除态）
- [ ] 「剔除内容」每行给状态标签（`剔除·重复份` / `剔除·页眉` 等）、页码、文本与剔除依据；角标数与详情统计的"不进切片总数"一致
- [ ] 「字段」页签列出标准化字段：类型（金额 / 日期 / 面积 / 证书号）+ 值（带单位）+ 来源元素类型与页码 + 命中规则；没有字段时给空态
- [ ] 「过程」页签九步齐全（编码规范化 → 文本整理 → 页眉页脚 → 目录 → 重复 → 字段规范化 → 噪声 → 自定义规则 → 视图组装），失败步骤带红条与错误摘要
- [ ] 「告警」页签：预处理产物没有独立告警清单 → 给空态；统计条的告警数与「过程」页签各步告警数之和一致

## 五、左栏「清洗后的正文」

- [ ] 栏头显示「清洗后的正文 · 共 N 个保留元素 · 已剔除 M」
- [ ] 默认「只看保留」：不进切片的元素不出现
- [ ] 切「看被剔除」：被剔除的块**灰化划线留在原位**并带状态标签；再切回来恢复
- [ ] 元素排版正确：标题 / 段落 / 分节 / 表格（真表格，表头有底色）/ 图片占位 / 页眉页脚（弱化 + 类型标签）
- [ ] 长文档滚动到底会继续追加渲染（一次 80 块），不出现白屏或一次性卡死
- [ ] 产物不可读的任务：左栏给中性提示，不显示半截文档
- [ ] 换一次运行 → 左栏回到「只看保留」档、渲染窗口从头开始

## 六、双向定位

- [ ] 点右栏某行 → 左栏滚到对应块并高亮（目标未渲染时先补渲染窗口）
- [ ] 点左栏的块 → 右栏对应行选中并滚入视野；目标不在当前页时先切到它所在页
- [ ] 在「只看保留」档下，从「剔除内容」点一行 → **自动切到「看被剔除」档**并滚到它的原位
- [ ] 点一个不属于当前产物的 id → 只保留选中，不做近似匹配

## 七、越权与边界

- [ ] 用别人的 `fileResultId` 打开详情 / 触发 → 40401（与"不存在"同一响应）
- [ ] 未登录（清掉令牌）→ 40101
- [ ] `taskId` 传另一个文件的任务 → 40001

## 八、规则档位（策略页 → 结果核对）

- [ ] 策略页四条三态规则（页眉页脚 / 目录 / 噪声 / 重复段落·页）都是三选一：保留 / 标记 / 剔除；每条都有一句说明写清「保留 = 只统计不处置」「标记 = 保留但标注」「剔除 = 不进检索内容流」
- [ ] 「重复段落 / 页去重」默认档 = 剔除；只有旧开关格式的配置打开时按「开 = 剔除、关 = 保留」显示
- [ ] 重复档选「剔除」→ 重复份进「剔除内容」页签、状态标签 `剔除·重复份`、统计条「重复」格计数、不计进「仅标记」
- [ ] 重复档选「标记」→ 重复份**不**进「剔除内容」、计进「仅标记」、状态标签 `仅标记·重复份`、内容仍在切片里
- [ ] 重复档选「保留」→ 重复份状态回落正常（元素无状态标签），重复内容与首份都在切片里
- [ ] 噪声档选「保留」→ 噪声页元素不再被标注（不再等同「标记」），组装侧的噪声页标记与告警计数仍在
- [ ] 目录两个阈值（每页最少行数 / 连续 run 最短长度）在三种档位下都生效，选「保留」也不失效
- [ ] 文本整理的「折行段落合并」开关：关掉后同段内硬折行保持原样（段间空行与列表项本来就不合并）
- [ ] 改完档位要**重新触发**预处理才生效：新运行按新档位，旧任务与旧产物保持原样

## 九、回归一眼（解析 / 组装）

- [ ] 解析卡片与详情：统计项、左栏原文预览、四个页签、双向定位与本轮之前一致
- [ ] 组装卡片：体检清单五行与结论行不变；详情左栏「组装后的文档」排版与「结构树」页签分页不变
- [ ] 两个环节的抽屉**都看不到「第 N 次执行」**（本轮已从所有环节移除）
