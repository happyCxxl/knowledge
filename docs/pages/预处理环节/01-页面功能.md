# 页面功能

预处理环节在执行链页上表现为**一张清洗卡片**，点卡片上的「详情」打开**环节详情抽屉**（各环节共用同一组件）。卡片与抽屉都是只看不改的展示面，唯一的写操作是卡片上的「触发下一环节」。

## 一、清洗卡片

卡片固定 320 × 214，任何状态下尺寸与行位不变。预处理卡片是**五个行位**：主体区由清洗体检清单顶替解析卡片的「指标行 + 构成图」。

| 行       | 内容                       | 说明                                                                                               |
|----------|----------------------------|----------------------------------------------------------------------------------------------------|
| ① 标题行 | 环节名 + 状态点            | 状态点按任务状态取色                                                                               |
| ② 标识行 | 策略版本                   | 取执行树节点的策略版本（name-version 串，如 `preproc-default-v1`）；取不到时留空并弱化，不显示 `—` |
| ③ 主体区 | 清洗体检清单（五行）       | 每行 = 状态点 + 项目名 + 关键量 + 说明；**不显示指标行**（计数都在清单里）                         |
| ④ 结论行 | 结论一句话                 | 最多两行，超出省略；完整文案在悬停提示里                                                           |
| ⑤ 操作行 | 时间 + 详情 + 触发下一环节 | 未完成显示开始时间，完成显示结束时间；悬停给完整起止（带秒）                                       |

**身份行只有策略版本**：统一文档与派生视图产物里都没有"视图 schema"这类版本字段，产物契约不改就拿不到，故留空而不编造。

### 清洗体检清单五行

| 项目     | 关键量             | 说明列                                              | 绿（正常）      | 黄（需关注）    |
|----------|--------------------|-----------------------------------------------------|-----------------|-----------------|
| 剔除元素 | **不进切片的总数** | `重复份 N · 剔除 M，不进检索`（无剔除给「无剔除」） | 0 个            | > 0 个          |
| 仅标记   | `markedCount`      | `页眉 N · 页脚 M · 目录 K · 噪声 J`                 | 0 个            | > 0 个          |
| 字段规范 | `fieldCount`       | `金额 N · 日期 M · 面积 K · 证书号 J`               | 提过字段（> 0） | —（无字段记灰） |
| 文本改写 | `changedCount`     | `编码 N · 整理 M`                                   | 有改写（> 0）   | —（无改写记灰） |
| 保留元素 | `retainedCount`    | `占 N%`（保留占比）                                 | 没有剔除        | 有剔除          |

口径要点：

- 卡片「剔除元素」一行取的是**不进切片的总数** = 剔除态元素 + 重复份（`chunkSkippedCount`），与设计稿"剔除 14（重复份）"一致；
- 而详情统计条把「剔除」与「重复」**分两格**：`excludedCount` **不含重复份**（页眉 / 页脚 / 目录 / 噪声被剔除与组装冲突被裁决方），`repeatedCount` 单列；
- 统计缺失（产物读不出来）时整行落到**灰 + `—`**，不冒充真实值；「字段规范」「文本改写」两行在"没有"与"是零"之间不做区分，一律灰。

### 四态

状态与解析环节同一套：`QUEUED` 排队中 / `RUNNING` 运行中 / `SUCCESS` 成功 / `PARTIAL_SUCCESS` 部分成功 / `FAILED` 失败 / `CANCELLED` 已取消（视觉归为进行中 / 成功 / 部分成功 / 失败四类）。

- 卡片**不显示错误原因**，失败只靠左侧红条与状态点颜色表达，原因在抽屉的失败条里；
- **预处理会产出「部分成功」**：某条规则对某个元素抛异常时，该元素照常产出、异常计入子步骤告警与结论（见下）。

### 结论文案（后端给，卡片与抽屉统计条同一句）

| 情形                      | 结论                                                                                              |
|---------------------------|---------------------------------------------------------------------------------------------------|
| 进行中                    | 「正在预处理…」（前端文案）                                                                       |
| 失败 / 已取消             | `errorMsg`                                                                                        |
| 成功 / 部分成功，统计缺失 | **留空**（产物不可读时不陈述结论）                                                                |
| 成功 / 部分成功，空视图   | 「无任何可处理的元素（空视图）」                                                                  |
| 成功 / 部分成功，无异常项 | 「未剔除内容，全部进入切片」                                                                      |
| 成功 / 部分成功，有异常项 | 「N 项仅标记、仍在检索内容流；M 项已剔除出检索内容流；重复份 K 已剔除」（只陈述异常项，顺序固定） |

### 触发与分叉

- 预处理卡片的「触发下一环节」= **切片**；分叉点是**被点那张卡的预处理产物**（本节点 `productId` 作为 `upstreamProductId` 传给切片触发接口），同一份文件的多次预处理可以各走各的下游；
- 按钮常驻，只有「能点 / 不能点」两态：本节点有产物即可点，不可点时置灰并给原因（任务未完成 → 「任务完成后可用」；已完成但无产物 → 「本次运行没有产物」）；
- 触发时按**策略四档**解析生效版本（见 `03-接口逻辑.md`），策略快照在触发时固定，执行只用快照；成功后**再次触发是重跑**（新建一条运行，旧任务与旧产物保留）。

## 二、预处理详情抽屉

四个固定分区，与解析 / 组装同一套版式（高度锁在视口内，滚动只发生在双栏各自的容器里）：

| 分区   | 固定方式         | 内容                                                                                  |
|--------|------------------|---------------------------------------------------------------------------------------|
| 头部   | 固定             | 文件名 + 状态徽标 + 开始时间 / 耗时 / 任务 ID                                         |
| 统计条 | 固定             | 结论一句话 + 八格统计：元素 / 保留 / 剔除 / 仅标记 / 重复 / 字段 / 告警 / 耗时        |
| 失败条 | 固定，仅失败出现 | 错误码 + 失败说明 + 建议动作（`PREPROCESS_EMPTY` / `PREPROCESS_FAILED` 各给对应建议） |
| 双栏   | 唯一伸缩的分区   | 左栏清洗后的正文、右栏清洗结果与剔除内容等，**各自滚动**                              |
| 底部   | 固定             | 下载原文件 / 复制全部文本（复制的是右栏当前页文本）                                   |

统计条八格的口径：**剔除**取 `excludedCount`（不含重复份）、**重复**单列（`repeatedCount`）、**仅标记**取 `markedCount`、**告警**取子步骤告警数之和（产物里没有独立的告警清单）。

### 右栏页签

「清洗结果（默认）/ 剔除内容 / 字段 / 过程 / 告警」五个，页签条固定在右栏顶部，内容各自滚动；角标是条数（为 0 不显示数字）。

- **打开抽屉默认落在该环节页签表的第一项**（预处理 = 「清洗结果」）；切换环节或重新打开回到默认页签；
- **同一环节内切换到另一次运行保留当前页签**；切页签不影响左栏位置与选中状态。

| 页签     | 内容                                                                                                                              |
|----------|-----------------------------------------------------------------------------------------------------------------------------------|
| 清洗结果 | 分页元素列表：类型徽标 + 序号 + 页码 + 来源 + 表格行列，文本默认两行折叠可展开；关键字过滤只作用于当前页                          |
| 剔除内容 | **只列不进切片的元素**（剔除态 + 重复份，按 `status` 过滤分页）：类型徽标 + 状态标签 + 页码 + 文本 + 剔除依据（轨迹证据或规则名） |
| 字段     | 标准化字段一览：字段类型 + 值（带单位）+ 来源元素类型与页码 + 命中规则                                                            |
| 过程     | 九步子步骤：步骤名 / 状态 / 耗时 / 告警数 / 错误；失败的步骤带红条                                                                |
| 告警     | 告警与冲突列表；预处理产物没有独立告警清单，此处给空态（告警数看统计条与「过程」页签）                                            |

「剔除内容」是**按需加载**的：切到该页签时才取列表（角标数直接用详情统计，不必先请求）；分页每页 100 条，与「清洗结果」各自独立翻页。

### 左栏：清洗后的正文

左栏把派生视图元素排成一份文档（与组装环节同一套排版口径），顶部有**两档切换**：

| 档位     | 显示                                                                                             |
|----------|--------------------------------------------------------------------------------------------------|
| 只看保留 | 只渲染进切片的元素（默认档）                                                                     |
| 看被剔除 | 渲染全部元素，**不进切片的块灰化划线留在原位**，并带状态标签（`剔除·重复份` / `仅标记·页眉` 等） |

- 元素类型排版与组装一致：`TITLE` / `SECTION` / `PARAGRAPH` / `TABLE`（按单元格行列渲染真表格）/ `IMAGE`（占位框）/ `HEADER`/`FOOTER`（弱化 + 类型标签）/ 其余按文本；
- 正文取**展示文本**（`displayText`），缺展示文本时回落原文（`rawText`）；**视图不带标题层级**，标题按单档呈现；
- 栏头：「清洗后的正文 · 共 N 个保留元素 · 已剔除 M」，未渲染完时补「已渲染 X」；
- **按需渲染**：一次渲染 80 块，滚动接近底部再追加，不做硬性分页；点定位时先把目标块补进渲染窗口；
- 产物不可读或无产物时给中性提示。

### 双向定位（左栏文档 ↔ 右栏列表）

两侧都以**产物元素 id** 对齐：左栏块键取视图元素的 `elementId`，右栏行键取 `stage-content` 的 `alignKey`，两者是同一个 id。

| 操作                                | 结果                                               |
|-------------------------------------|----------------------------------------------------|
| 点右栏「清洗结果」/「剔除内容」某行 | 左栏滚到对应块并高亮；目标块还没渲染时先补渲染窗口 |
| 点左栏文档里的块                    | 右栏对应行选中并滚入视野（目标不在当前页时先切页） |
| 点在「只看保留」档下被剔除的元素    | **自动切到「看被剔除」档**再滚到它的原位           |
| id 不在当前产物里                   | 只保留选中，不做顺序近似匹配                       |

## 三、失败态与建议动作

| 错误码              | 建议动作                                                                   |
|---------------------|----------------------------------------------------------------------------|
| `PREPROCESS_EMPTY`  | 上游组装产物缺失或读不到：确认组装已成功产出产物后再触发预处理             |
| `PREPROCESS_FAILED` | 预处理执行异常：看「过程」页签里失败的步骤，必要时重新触发一次预处理       |
| 其它 / 无产物       | 本次运行没有产物：确认文件可用后，从页面工具栏发起解析（会新建一条执行链） |
