# 布局壳（菜单 / 返回 / 退出登录）

壳**没有独立路由**：它是父路由 `/`（`redirect: /home`），7 个子页面都渲染在它的内容区里。壳自身不调任何后端接口——账号相关能力（个人信息、修改密码）已是独立页面，见 `../个人中心/`。

| 项         | 值                                                                                                                 |
|------------|--------------------------------------------------------------------------------------------------------------------|
| 路由       | 无独立路由（父路由 `/`，`redirect: /home`）                                                                        |
| 前端视图   | `../../../web/src/layouts/AppLayout.vue`                                                                           |
| 子页面     | `home`、`knowledge-base`、`knowledge-base/:id/stages`、`.../index`、`.../retrieval`、`strategy`、`user`、`profile` |
| 路由与守卫 | `../../../web/src/router/index.ts`（守卫口径见 `../../README.md` 的「全局约定」章第四节）                          |
| 涉及接口   | 无（壳只管骨架；账号信息与改密见 `../个人中心/`）                                                                  |

路由与 `meta` 的守卫行为、登录态与令牌口径都在根文档的全局约定里写过了，本页不复述。

| `04-自测清单.md` | 改完要手工验哪些点、期望结果                 | 每次交付前           |

**壳没有自有接口**，所以不建 `02-接口交互.md` / `03-接口逻辑.md`（按根文档「文档按需建」的约定）。账号相关能力在 `../个人中心/`，壳只负责把入口指过去。

## 待定项

- 管理权限目前有**两处独立声明**：菜单项的 `adminOnly` 与路由的 `meta.adminOnly`。新增管理类页面要同步改两处，漏前者入口不显示、漏后者能进但后端拒绝——是否需要收敛成一处（例如菜单从路由表反推），待定。

（原先那条「用户菜单在侧栏与顶栏两处重复、每处三项」已不是问题：两个入口现在都只指向同一页，个人中心移入主导航、两处下拉只留「退出登录」。）
