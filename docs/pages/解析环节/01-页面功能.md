# 页面功能

解析环节在执行链页上表现为**一张解析卡片**，点卡片上的「详情」打开**解析详情抽屉**。卡片与抽屉都是只看不改的展示面，唯一的写操作是卡片上的「触发下一环节」。

## 一、解析卡片

卡片固定 320 × 214，六个行位（任何状态下尺寸不变）：

| 行       | 内容                          | 说明                                                                                                                         |
|----------|-------------------------------|------------------------------------------------------------------------------------------------------------------------------|
| ① 标题行 | 环节名 + 状态点               | 状态点按任务状态取色                                                                                                         |
| ② 标识行 | 能力快照 · 策略版本           | 缺项显示 `—`                                                                                                                 |
| ③ 指标行 | 页数 / 元素数 / 耗时          | 缺项显示 `—`                                                                                                                 |
| ④ 构成图 | 正文 / 表格 / 图片 / 页眉页脚 | **一个类型一条**：类型标签 + 浅色槽 + 彩色条 + 数字；条长 = 该类元素数占元素总数的比例，比例大于 0 时至少 3px，为 0 时不出条 |
| ⑤ 摘要行 | 结论一句话                    | 最多两行，超出省略；缺结论时显示 `—`                                                                                         |
| ⑥ 操作行 | 时间 + 详情 + 触发下一环节    | 见下                                                                                                                         |

四种状态（`QUEUED` 排队中 / `RUNNING` 运行中 / `SUCCESS` 成功 / `PARTIAL_SUCCESS` 部分成功 / `FAILED` 失败 / `CANCELLED` 已取消，视觉上归为「进行中 / 成功 / 部分成功 / 失败」四类）：

- 卡片**不显示错误原因**，失败与否只靠左侧红条与状态点颜色表达；
- 时间显示**结束时间**（运行中显示开始时间），悬停给完整起止（带秒）；
- 未完成的节点也出现在链图上（排队中同样立刻可见）。

### 操作行的两个按钮

| 按钮         | 行为                                                                                                                                                              |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 详情         | 打开解析详情抽屉。**始终可点**                                                                                                                                    |
| 触发下一环节 | **始终渲染**，只有「能点 / 不能点」两态：本节点**有产物**即可点；不可点时置灰并给出原因（任务未完成 → 「任务完成后可用」；已完成但无产物 → 「本次运行没有产物」） |

**没有「再次执行同一环节」这个概念**：解析成功或部分成功之后不再允许从同一张卡片触发；要再来一次是从页面工具栏发起，会**新建一条执行链**（旧任务与旧产物保留）。

### 触发与分叉

「触发下一环节」按**被点的那张卡片**取上游：点哪张卡就用哪张卡的产物，因此同一份文件上的多次运行可以各走各的下游，形成分叉。解析是链路起点，没有上游产物，触发时不带 `upstreamProductId`。

触发成功后页面**立即刷新血缘**并把新节点展示为排队中，随后按固定间隔轮询直到任务进入终态（轮询上限 150 次）。

## 二、解析详情抽屉

抽屉宽 `min(1440px, 100vw)`，窄屏按视口收窄。**四个固定分区**纵向排开，高度锁在视口内，外层不出现整页滚动条：

| 分区   | 固定方式               | 内容                                                                                             |
|--------|------------------------|--------------------------------------------------------------------------------------------------|
| 头部   | 固定                   | 文件名 + 状态徽标 + 「第 N 次执行」/ 开始时间 / 耗时 / 任务 ID                                   |
| 统计条 | 固定                   | 结论一句话 + 八项统计（页 / 元素 / 正文 / 表格 / 图片 / 页眉页脚 / 问题单元 / 耗时），放不下换行 |
| 失败条 | 固定，仅解析失败时出现 | 错误码 + 失败说明 + 建议动作                                                                     |
| 双栏   | 唯一伸缩的分区         | 左栏原文预览、右栏解析结果，**各自滚动**                                                         |
| 底部   | 固定                   | 下载原文件 / 复制全部文本                                                                        |

### 右栏页签

「元素 / 告警 / 过程」三个页签，页签条固定在右栏顶部，**页签内容各自滚动**。角标显示条数（为 0 时不显示数字）。切页签**不影响左栏位置、页码与选中状态**。

| 页签 | 内容                                                                                               |
|------|----------------------------------------------------------------------------------------------------|
| 元素 | 关键字过滤 + 元素列表 + 翻页；每条显示类型徽标、序号、页码、来源、表格行列，文本默认两行折叠可展开 |
| 告警 | 告警列表；文案里的「第 N 页 / 第 N–M 页」渲染成可点链接，点击左右两栏同跳该页。无告警时显示空态    |
| 过程 | 子步骤列表：步骤名 / 状态 / 耗时 / 告警数 / 错误；失败的步骤带红条。无记录时显示空态               |

### 分隔条

左右两栏之间是 6px 的竖直分隔条（命中区向两侧各扩 3px）：

| 操作   | 行为                                              |
|--------|---------------------------------------------------|
| 拖动   | 调整两栏宽度；拖动中分隔条高亮、不选中文字        |
| 双击   | 恢复默认比例（左栏 62%）                          |
| 方向键 | 可聚焦，`←/→` 每次 24px 微调，`Home`/`End` 到两端 |

- 约束：左栏最小 320px、右栏最小 360px，夹住后不产生横向滚动条；
- 比例按「文件结果 + 任务」持久化到 `localStorage`，再次打开该次运行沿用；
- 双击恢复默认时会清掉记录。

### 左栏原文预览

按文件后缀分派，**只影响左栏**（预览失败或类型不支持时右栏解析结果照常可看；解析失败时左栏照常渲染原文件）：

| 类型             | 预览                                                                                    | 工具条                                   |
|------------------|-----------------------------------------------------------------------------------------|------------------------------------------|
| PDF              | pdf.js 按页渲染，只渲染视野内的页，可画元素高亮框                                       | 上一页 / 下一页 / 页码 / 适应宽度 / 缩放 |
| DOCX             | docx-preview 渲染文档                                                                   | 缩放                                     |
| XLSX             | SheetJS 读为网格，显示工作表页签与行号列，**单表最多 200 行 × 60 列**（超出提示已截断） | 工作表切换                               |
| DOC / XLS / 其它 | 降级：文件信息 + 提示用底部「下载原文件」                                               | —                                        |

## 三、五条联动

| # | 操作               | 结果                                                           |
|---|--------------------|----------------------------------------------------------------|
| 1 | 左栏翻页           | 右栏切到该页元素（「只列预览当前页」开启时按页重取）           |
| 2 | 右栏点元素         | 左栏定位并高亮：PDF 画边界框、Word 段落底色、Excel 单元格底色  |
| 3 | 左栏点原文         | 按坐标命中元素，右栏滚动到该条并选中；点空白处清除点选         |
| 4 | 点告警里的页码范围 | 左右两栏同跳该页                                               |
| 5 | 拖分隔条           | 两栏宽度变化，左栏内容跟随栏宽（「适应宽度」开启时缩放跟着变） |

## 四、失败态与建议动作

解析失败时抽屉固定区出现失败条，按错误码给不同的下一步动作：

| 错误码                  | 建议动作                                                                 |
|-------------------------|--------------------------------------------------------------------------|
| `PARSE_CORRUPTED`       | 确认文件未损坏，或用带文本层的版本重新导出后，从页面工具栏再发起一次解析 |
| `SCANNED_UNSUPPORTED`   | 纯扫描件暂不支持，请提供带文本层的 PDF                                   |
| `RATIO_BELOW_THRESHOLD` | 成功单元占比过低，检查是否有大量扫描页或乱码，换一版文件后重新发起       |
| 其它 / 无产物           | 确认文件可用后，从页面工具栏发起解析（会新建一条执行链）                 |

## 五、列表与过滤的口径

- 元素列表**分页**：每页 100 条，后端另有默认上限与上限；`total` 是该次运行产物内容的总条数（按文档页过滤后为该页条数）；
- 关键字过滤**只作用于当前页**（后端按页给内容），页面明确标注「只过滤当前页」；
- 「只列预览当前页」开关默认开启：开启时右栏按左栏当前页取元素，关闭时右栏看全量列表；
- 「复制全部文本」复制的是**当前页已取回的文本**，并按实际条数提示。
